Get a robot moving
================

Goal: Making the robot drive with the base code.

Do this exactly
---------------

1. Using hardware configurator, flash motor controllers with CAN IDs
2. Open ``frc.robot.constants``
3. Set drivetrain CAN IDs
4. Deploy code to robot
5. Enable robot


Expected result
---------------

- Robot drives (direction may be wrong)
- No runtime errors


If this fails
-------------

Go to :doc:`bringup-test`
