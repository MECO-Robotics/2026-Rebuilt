Set Hardware IDs
============

Set CAN IDs and ports to match your robot.


Where
-----

``frc.robot.constants``


Do this
-------

- Assign CAN IDs for drivetrain
- Assign CAN IDs for mechanisms
- Match physical wiring


Expected result
---------------

- All devices appear on network
- No CAN conflicts


Common mistakes
---------------

- Duplicate CAN IDs
- Wrong device type
- Mismatch between wiring and constants
